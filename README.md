## ConcertTicketDB
Final project for CS:4400 Database Systems\
Group #: 8\
Members: Tallen Lawrence, Ryan Merza, Joshua Sim

## Project Description

For this project we were assigned the task of developing a full stack database system. From basic database planning, designing an ER diagram, to the physical mySQL implementation, to developing a front end for easy use. For our project we decided to focus on implementing a concert ticket database, which keeps track of customers and what reward tier their accounts as well as what bookings they have. Each booking has at least 1 ticket associated with it, and each ticket is associated with one concert which has one venue, and one or more performer. Each venue has one or more employees.

For implementation of the database, we used mySQL. For implementation of the website we used PHP.
